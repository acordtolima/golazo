# Ozil Goal AI App

App para recrear el gol de Özil con IA a partir de una foto.

## Uso

```bash
npm install
npm run dev
```

## Variables de entorno

```env
RUNWARE_API_KEY=tu_api_key_aqui
OZIL_BASE_VIDEO_URL=https://pub-d32207fa9a73400ca3dd385d6d72f436.r2.dev/golaco.mp4
```

## Despliegue

Listo para Vercel. Configura las variables de entorno en el dashboard.
